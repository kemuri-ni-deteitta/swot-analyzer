# Как запустить приложение

## Запуск в режиме разработки

```bash
npm run electron:dev
```

### Что происходит:

1. **Vite dev server** запускается на `http://localhost:5173`
2. **Electron** автоматически открывает окно приложения
3. Окно подключается к dev server

### Если Electron окно не открылось:

1. Проверьте, что Vite запустился (должно быть сообщение "Local: http://localhost:5173")
2. Подождите несколько секунд - Electron ждёт, пока сервер запустится
3. Если окно не появилось, откройте вручную:
   ```bash
   electron .
   ```
   (но сначала убедитесь, что Vite работает на порту 5173)

## Альтернативный способ (только Vite, без Electron):

Если нужно просто посмотреть веб-версию:

```bash
npm run dev
```

Затем откройте в браузере: http://localhost:5173

**Внимание**: В веб-версии не будет работать сохранение файлов (Electron API недоступен), но можно тестировать UI.

## Решение проблемы ENOSPC (лимит file watchers)

Если видите ошибку `ENOSPC: System limit for number of file watchers reached`:

### Временное решение (до перезагрузки):
```bash
echo fs.inotify.max_user_watches=524288 | sudo tee -a /etc/sysctl.conf
sudo sysctl -p
```

### Проверка текущего лимита:
```bash
cat /proc/sys/fs/inotify/max_user_watches
```

## Горячие клавиши (в Electron)

- `Ctrl+R` или `F5` - перезагрузить окно
- `Ctrl+Shift+I` - открыть DevTools
- `Ctrl+W` - закрыть окно

## Остановка приложения

Нажмите `Ctrl+C` в терминале, где запущена команда `npm run electron:dev`

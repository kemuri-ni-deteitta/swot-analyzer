# Быстрый старт

## Запуск в режиме разработки

```bash
npm run electron:dev
```

Это команда запустит:
1. Vite dev server на http://localhost:5173
2. Electron приложение, которое подключится к dev server

## Что дальше?

1. **Протестировать Project Hub (Этап 0)**:
   - Создать новый проект
   - Открыть существующий проект
   - Удалить проект

2. **Реализовать остальные этапы**:
   - Этап 1: Ввод факторов (таблица с фильтрацией)
   - Этап 2: Расчёт и проверка (валидация)
   - Этап 3: Визуализация (SWOT матрица, графики)
   - Этап 4: Стратегии
   - Этап 5: Итог

## Структура данных

Проекты сохраняются в:
- **Linux/Mac**: `~/SWOTProjects/`
- **Windows**: `%USERPROFILE%\SWOTProjects\`

Каждый проект = один JSON файл `{project_id}.json`

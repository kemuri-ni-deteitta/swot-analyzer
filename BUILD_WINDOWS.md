# 🪟 Сборка приложения для Windows

## Быстрый старт

### Шаг 1: Установите зависимости (если ещё не установлены)

```bash
npm install
```

### Шаг 2: Соберите приложение

```bash
npm run electron:build:win
```

Это создаст установщик Windows в папке `dist-electron/`.

## Что получится

После сборки в папке `dist-electron/` будет файл:
- **`SWOT Analyzer Setup x.x.x.exe`** - установщик Windows (NSIS)

## Установка на Windows

1. Скопируйте файл `.exe` на Windows компьютер
2. Запустите установщик
3. Следуйте инструкциям установщика
4. Приложение будет установлено и появится в меню "Пуск"

## Что включено в установщик

✅ Весь React код (скомпилированный)  
✅ Electron runtime (Chromium + Node.js)  
✅ Все зависимости  
✅ Файловые ассоциации для `.swot` файлов  
✅ Ярлыки на рабочем столе и в меню "Пуск"

## Размер установщика

Ожидаемый размер: **~100-150 MB**

Это нормально для Electron приложений, так как они включают в себя:
- Chromium (браузерный движок)
- Node.js runtime
- Все зависимости приложения

## Сборка на Linux для Windows

Если вы на Linux, но хотите собрать .exe для Windows:

### Вариант 1: Использовать Wine (не рекомендуется)

```bash
# Установка wine
sudo apt-get install wine

# Сборка (может работать нестабильно)
npm run electron:build:win
```

### Вариант 2: Использовать Docker (рекомендуется)

```bash
# Используйте Windows образ Docker
docker run -v $(pwd):/app -w /app node:20 npm run electron:build:win
```

### Вариант 3: GitHub Actions (лучший вариант)

Создайте файл `.github/workflows/build-windows.yml`:

```yaml
name: Build Windows

on:
  push:
    tags:
      - 'v*'

jobs:
  build:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
        with:
          node-version: '20'
      - run: npm install
      - run: npm run electron:build:win
      - uses: actions/upload-artifact@v3
        with:
          name: windows-installer
          path: dist-electron/*.exe
```

## Настройка иконки

Для Windows нужна иконка в формате `.ico`:
- Путь: `resources/icon.ico`
- Рекомендуемые размеры: 256x256, 128x128, 64x64, 48x48, 32x32, 16x16

**Если иконки нет:**
- Сборка всё равно пройдёт, но будет использована стандартная иконка Electron
- Или создайте простую иконку через онлайн-конвертер (например, convertio.co)

## Устранение проблем

### Ошибка "icon not found"

Если иконка отсутствует, временно уберите строку из `package.json`:

```json
"win": {
  "target": [{"target": "nsis", "arch": ["x64"]}]
  // "icon": "resources/icon.ico"  // закомментируйте эту строку
}
```

### Ошибка при сборке TypeScript

```bash
# Проверьте, что TypeScript компилируется
npm run build
```

### Ошибка "Cannot find module"

```bash
# Переустановите зависимости
rm -rf node_modules package-lock.json
npm install
```

### Большой размер файла

Это нормально для Electron приложений. Если нужно уменьшить размер:
- Используйте `electron-builder` с настройками для исключения ненужных файлов
- Или используйте `asar` для упаковки файлов

## Проверка сборки

После сборки проверьте:

1. **Размер файла**: должен быть ~100-150 MB
2. **Имя файла**: `SWOT Analyzer Setup x.x.x.exe`
3. **Расположение**: `dist-electron/`

## Распространение

### Для пользователей:

1. Скачайте файл `.exe`
2. Запустите установщик
3. Следуйте инструкциям
4. Приложение установится и будет готово к использованию

### Безопасность:

- Windows может показать предупреждение "Неизвестный издатель" - это нормально для неподписанных приложений
- Пользователь может нажать "Дополнительно" → "Выполнить в любом случае"
- Для коммерческого распространения рекомендуется подписать приложение сертификатом

```bash

npm run electron:build:win
```

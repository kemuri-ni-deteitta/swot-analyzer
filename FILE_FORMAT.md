# Формат файла SWOT проекта

## Расширение файла

Проекты сохраняются с расширением **`.swot`**

Пример: `my-project.swot`

## Структура файла

Файл `.swot` представляет собой JSON с следующей структурой:

```json
{
  "header": {
    "signature": "SWOT",
    "formatVersion": 1,
    "appVersion": "1.0.0"
  },
  "project": {
    "id": "project-1234567890-abc",
    "name": "Название проекта",
    "description": "Описание проекта",
    "factors": [...],
    "strategies": [...],
    "createdAt": "2024-01-01T00:00:00.000Z",
    "updatedAt": "2024-01-01T00:00:00.000Z",
    "schemaVersion": "1.0.0",
    "appVersion": "1.0.0"
  }
}
```

## Заголовок файла (header)

- **signature**: `"SWOT"` - сигнатура файла для идентификации формата
- **formatVersion**: `1` - версия формата файла (для будущих расширений)
- **appVersion**: версия приложения, создавшего файл

## Данные проекта (project)

Стандартная структура проекта SWOT Analyzer:
- `id` - уникальный идентификатор проекта
- `name` - название проекта
- `description` - описание (опционально)
- `factors` - массив факторов SWOT
- `strategies` - массив стратегий
- `createdAt` - дата создания (ISO 8601)
- `updatedAt` - дата последнего обновления (ISO 8601)
- `schemaVersion` - версия схемы данных
- `appVersion` - версия приложения

## Преимущества формата .swot

1. **Уникальная идентификация**: Файлы однозначно ассоциируются с приложением
2. **Расширяемость**: Заголовок позволяет добавлять новые поля без нарушения совместимости
3. **Валидация**: Сигнатура "SWOT" позволяет проверить, что файл действительно является проектом SWOT Analyzer
4. **Версионирование**: formatVersion позволяет мигрировать старые файлы на новый формат
5. **Переносимость**: JSON формат легко читается и переносится между системами

## Совместимость

Приложение поддерживает:
- ✅ Новый формат `.swot` (с заголовком)
- ✅ Старый формат `.json` (для обратной совместимости)

При открытии старого `.json` файла он автоматически конвертируется в новый формат при следующем сохранении.

## Открытие файлов

Файлы `.swot` можно открывать:
1. **Через меню**: File → Open
2. **Перетаскиванием**: Drag & Drop файла в окно приложения
3. **Двойным кликом**: После установки приложения файлы будут ассоциированы с приложением

## Сохранение файлов

Проекты сохраняются:
1. **Автоматически**: В `~/SWOTProjects/` с расширением `.swot`
2. **Вручную**: File → Save (Ctrl+S / Cmd+S)
3. **Как**: File → Save As... (Ctrl+Shift+S / Cmd+Shift+S) - позволяет выбрать место сохранения

## Миграция формата

При изменении `formatVersion` в будущем:
1. Приложение проверяет версию при открытии файла
2. Если версия старше - выполняется миграция данных
3. Если версия новее - показывается предупреждение

## Пример использования

```typescript
// Сохранение проекта
const project = { id: '...', name: '...', ... }
await storageService.saveProject(project, true)  // true = использовать .swot формат

// Открытие проекта из файла
const project = await storageService.openProjectFromFile()

// Сохранение как...
await storageService.saveProjectAs(project)
```

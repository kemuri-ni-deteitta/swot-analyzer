## О проекте

**SWOT Analyzer** — настольное приложение для автоматизированного проведения SWOT-анализа.

Программа помогает последовательно пройти весь аналитический процесс:

```text
Создание проекта
      ↓
Создание расчёта
      ↓
Ввод факторов S / W / O / T
      ↓
Количественная оценка
      ↓
Расчёт взаимодействий
      ↓
Визуализация результатов
      ↓
Генерация стратегий
      ↓
Итоговый отчёт
      ↓
Экспорт в PDF / DOCX
```

Приложение работает локально, не требует backend-сервера, базы данных или подключения к облачным сервисам. Проекты сохраняются непосредственно на компьютере пользователя.

# SWOT-факторы

Поддерживаются четыре стандартных типа факторов:

| Код | Тип | Смысл |
|---|---|---|
| `S` | Strengths | сильные стороны |
| `W` | Weaknesses | слабые стороны |
| `O` | Opportunities | возможности |
| `T` | Threats | угрозы |

Для фактора могут задаваться:

```text
Тип
Текст
Категория
Значимость
Влияние
Вероятность
Дополнительные пользовательские показатели
```

Базовые диапазоны:

```text
Значимость:  1 ... 5
Влияние:     1 ... 5
Вероятность: 0 ... 1
```

Для возможностей и угроз вероятность является обязательным параметром.

# Модели расчёта

В текущей версии приложения реализовано несколько вариантов расчёта.

## Стандартная модель взаимодействий

Для пары внутреннего и внешнего факторов используется:

```text
Aij = Ai × Kj × Pj
```

где:

```text
Ai — значимость внутреннего фактора S/W
Kj — значимость внешнего фактора O/T
Pj — вероятность реализации внешнего фактора
```

Пример:

```text
Ai = 5
Kj = 4
Pj = 0.8

Aij = 5 × 4 × 0.8 = 16
```

Для всех сочетаний внутренних и внешних факторов формируется матрица взаимодействий.

---

## Расширенная модель оценки факторов

Также реализована модель, соответствующая формуле, указанной в реферате государственной регистрации программы.

Для внутренних факторов:

```text
S / W:

score = significance × impact
```

Для внешних факторов:

```text
O / T:

score = significance × impact × probability
```

Например:

```text
significance = 5
impact       = 4
probability  = 0.8

External score = 5 × 4 × 0.8 = 16
```

## Пользовательские формулы

Проект также содержит редактор пользовательских профилей расчёта.

Можно определить собственную формулу оценки фактора:

```text
significance * impact
```

или взаимодействия:

```text
ai * kj * pj
```

Поддерживается добавление собственных числовых полей:

```text
Название
Ключ переменной
Минимальное значение
Максимальное значение
Значение по умолчанию
Шаг
Типы SWOT-факторов
```

Таким образом расчётная модель может быть адаптирована под конкретную методику анализа.

# Матрица взаимодействий

Для стандартной модели приложение автоматически строит связи между:

```text
Внутренние факторы
S / W

        ×

Внешние факторы
O / T
```

Для каждой пары рассчитывается `Aij`.

Пример:

```text
                O1       O2       T1       T2      Σ

S1             A11      A12      A13      A14     ...
S2             A21      A22      A23      A24     ...
W1             A31      A32      A33      A34     ...
W2             A41      A42      A43      A44     ...

Σ              ...      ...      ...      ...
```

Дополнительно рассчитываются:

- суммы по строкам;
- суммы по столбцам;
- общая сумма взаимодействий;
- агрегированные показатели по квадрантам.

# Генерация стратегий

После расчёта программа автоматически формирует стратегии четырёх классических типов SWOT.

| Тип | Сочетание | Назначение |
|---|---|---|
| `SO` | Strengths + Opportunities | использование сильных сторон для реализации возможностей |
| `WO` | Weaknesses + Opportunities | использование возможностей для преодоления слабостей |
| `ST` | Strengths + Threats | использование сильных сторон для противодействия угрозам |
| `WT` | Weaknesses + Threats | минимизация слабостей и угроз |

В зависимости от выбранной модели стратегии строятся на основе:

```text
топ-факторов
```

или:

```text
топ-взаимодействий
```

Пользователь может выбрать глубину анализа:

```text
Top 5
Top 7
Top 10
```

Для каждой стратегии отображаются:

- тип;
- название;
- описание;
- ключевые факторы;
- приоритет или суммарная оценка взаимодействия.

# Этапы работы в приложении

Интерфейс организован как последовательный аналитический workflow из семи этапов:

```text
1. Проекты
      ↓
2. Расчёты
      ↓
3. Ввод факторов
      ↓
4. Взаимодействия
      ↓
5. Визуализация
      ↓
6. Стратегии
      ↓
7. Итог
```

Такой подход разделяет процесс SWOT-анализа на понятные шаги и позволяет возвращаться к предыдущим этапам без потери данных.

## 🎯 Назначение программы

**SWOT Analyzer** — это настольное приложение для проведения SWOT-анализа проектов, бизнес-идей и стратегических решений. Программа помогает структурированно собирать, анализировать и визуализировать факторы, влияющие на объект анализа, а также автоматически генерировать стратегические рекомендации.

### Для кого предназначена программа:

- **Бизнес-аналитики** — для анализа компаний и продуктов
- **Менеджеры проектов** — для оценки проектных рисков и возможностей
- **Предприниматели** — для анализа бизнес-идей и стартапов
- **Студенты и исследователи** — для учебных и научных проектов
- **Консультанты** — для подготовки аналитических отчетов

## ✨ Основные возможности

### 1. Управление проектами
- Создание неограниченного количества проектов SWOT-анализа
- Сохранение и загрузка проектов
- Автоматическое сохранение изменений
- Удаление проектов

### 2. Ввод и управление факторами
- Добавление факторов четырех типов:
  - **S (Strengths / Сильные стороны)** — внутренние преимущества
  - **W (Weaknesses / Слабые стороны)** — внутренние недостатки
  - **O (Opportunities / Возможности)** — внешние возможности
  - **T (Threats / Угрозы)** — внешние угрозы
- Категоризация факторов
- Оценка значимости и влияния (1-5)
- Оценка вероятности для возможностей и угроз (1-5)
- Автоматический расчет оценки факторов
- Редактирование и удаление факторов
- Фильтрация и сортировка факторов

### 3. Расчеты и анализ
- Автоматический расчет оценок факторов:
  - Для S/W: `Оценка = Значимость × Влияние`
  - Для O/T: `Оценка = Значимость × Влияние × Вероятность`
- Подсчет сумм по квадрантам SWOT-матрицы
- Анализ по категориям
- Определение топ-факторов

### 4. Визуализация
- SWOT-матрица 2×2 с визуализацией квадрантов
- Столбчатые диаграммы по категориям
- Графики распределения факторов
- Топ-10 факторов по оценке

### 5. Генерация стратегий
- Автоматическая генерация четырех типов стратегий:
  - **SO (Strengths-Opportunities)** — агрессивные стратегии роста
  - **WO (Weaknesses-Opportunities)** — оборонительные стратегии развития
  - **ST (Strengths-Threats)** — защитные стратегии стабильности
  - **WT (Weaknesses-Threats)** — стратегии минимизации рисков
- Настройка количества топ-факторов для генерации (5, 7, 10)
- Диагностика доступности факторов для стратегий

### 6. Итоговый отчет
- Комплексная сводка по проекту
- Статистика факторов и стратегий
- Распределение по типам
- Топ-категории
- Рекомендации

### 7. Экспорт данных
- Экспорт отчета в **PDF** формат
- Экспорт отчета в **Word** формат (.docx)
- Сохранение проектов в собственном формате `.swot`
- Совместимость со старым форматом `.json`

### 8. Дополнительные функции
- Поддержка светлой и темной темы
- Файловые ассоциации для `.swot` файлов
- Автоматическое сохранение при изменениях
- Валидация ввода данных
- Виртуализация больших списков (производительность)

## 🔄 Этапы работы

Программа работает в 6 этапов:

### Этап 0: Проекты (Project Hub)
**Назначение:** Управление проектами SWOT-анализа

**Функции:**
- Просмотр списка всех сохраненных проектов
- Создание нового проекта (название, описание)
- Открытие существующего проекта
- Удаление проекта
- Отображение даты последнего обновления

### Этап 1: Ввод факторов
**Назначение:** Добавление и редактирование факторов анализа

**Функции:**
- Форма добавления факторов с полями:
  - Тип фактора (S/W/O/T)
  - Категория (обязательное поле)
  - Текст фактора
  - Значимость (1-5)
  - Влияние (1-5)
  - Вероятность (1-5, только для O/T)
- Таблица всех факторов с возможностью:
  - Редактирования полей
  - Удаления факторов
  - Фильтрации по типу и категории
  - Поиска по тексту
  - Сортировки по оценке, типу, категории
- Валидация ввода:
  - Ограничение числовых полей диапазоном 1-5
  - Красная обводка при отсутствии категории
  - Предупреждения о необходимости заполнения полей

### Этап 2: Расчёт и проверка
**Назначение:** Проверка корректности данных и просмотр статистики

**Функции:**
- Отображение общей статистики:
  - Общее количество факторов
  - Количество факторов по типам (S/W/O/T)
- Проверка полноты данных
- Информация о распределении факторов

### Этап 3: Визуализация
**Назначение:** Графическое представление данных анализа

**Функции:**
- **SWOT-матрица 2×2:**
  - Четыре квадранта (S, W, O, T)
  - Суммы оценок по каждому квадранту
  - Топ-3 фактора в каждом квадранте
- **Диаграммы:**
  - Столбчатые графики по категориям
  - Распределение факторов
- **Топ-10 факторов:**
  - Список факторов с наивысшими оценками
  - Отображение типа, текста, категории и оценки

### Этап 4: Стратегии
**Назначение:** Генерация и анализ стратегических рекомендаций

**Функции:**
- Настройка количества топ-факторов для генерации:
  - 5 факторов (стандартный анализ)
  - 7 факторов (детальный анализ)
  - 10 факторов (полный анализ)
- **Диагностика доступности факторов:**
  - Количество факторов каждого типа в топе
  - Список возможных стратегий
  - Предупреждения о недостающих типах факторов
- **Генерация стратегий:**
  - SO стратегии (агрессивные)
  - WO стратегии (оборонительные)
  - ST стратегии (защитные)
  - WT стратегии (минимизация рисков)
- Отображение для каждой стратегии:
  - Название и описание
  - Тип стратегии и её приоритет
  - Ключевые факторы, на основе которых сгенерирована стратегия
  - Подробное описание типа стратегии

### Этап 5: Итог
**Назначение:** Комплексный итоговый отчет по проекту

**Функции:**
- **Информация о проекте:**
  - Название и описание
  - Даты создания и обновления
  - Возраст проекта
- **Общая статистика:**
  - Количество факторов
  - Количество стратегий
- **Распределение факторов по типам:**
  - Количество и сумма оценок для каждого типа
- **SWOT-матрица:**
  - Визуальное представление всех квадрантов
- **Топ-5 категорий:**
  - Категории с наибольшими суммами оценок
- **Сгенерированные стратегии:**
  - Сводка по типам стратегий
- **Топ-10 факторов:**
  - Ранжированный список лучших факторов
- **Рекомендации:**
  - Автоматические рекомендации на основе данных
- **Экспорт отчетов:**
  - Кнопки экспорта в PDF и Word

## 🛠 Функциональность

### Управление данными

#### Создание проекта
1. Переход на этап "Проекты"
2. Заполнение формы:
   - Название проекта (обязательно)
   - Описание (опционально)
3. Нажатие "Создать проект"
4. Автоматический переход на этап "Ввод факторов"

#### Сохранение проекта
- **Автоматическое сохранение:**
  - При добавлении фактора
  - При изменении фактора
  - При удалении фактора
  - При генерации стратегий
  - При любом изменении данных проекта
- **Ручное сохранение:**
  - Через меню: File → Save (Ctrl+S)
  - Через меню: File → Save As... (Ctrl+Shift+S)

#### Открытие проекта
- Из списка проектов на этапе 0
- Через меню: File → Open Project... (Ctrl+O)
- Двойной клик на файл `.swot` в проводнике Windows

#### Формат файлов
- **Новый формат `.swot`:**
  - JSON-структура с заголовком
  - Сигнатура "SWOT"
  - Версия формата и приложения
  - Данные проекта
- **Совместимость:**
  - Поддержка старых файлов `.json`
  - Автоматическое определение формата

### Работа с факторами

#### Добавление фактора
1. Выбор типа фактора (S/W/O/T)
2. Ввод категории (обязательно)
3. Ввод текста фактора
4. Установка значимости (1-5)
5. Установка влияния (1-5)
6. Для O/T: установка вероятности (1-5)
7. Нажатие "Добавить"

#### Редактирование фактора
- Прямое редактирование в таблице факторов
- Изменение любого поля
- Автоматический пересчет оценки

#### Фильтрация факторов
- По типу (S/W/O/T/Все)
- По категории
- Поиск по тексту или категории

#### Сортировка факторов
- По оценке (по убыванию)
- По типу (алфавитно)
- По категории (алфавитно)

### Расчеты

#### Формулы расчета оценок
- **Для S (Сильные стороны) и W (Слабые стороны):**
  ```
  Оценка = Значимость × Влияние
  ```
  Диапазон: 1-25

- **Для O (Возможности) и T (Угрозы):**
  ```
  Оценка = Значимость × Влияние × Вероятность
  ```
  Диапазон: 1-125

#### Суммы по квадрантам
- ΣS — сумма всех оценок факторов типа S
- ΣW — сумма всех оценок факторов типа W
- ΣO — сумма всех оценок факторов типа O
- ΣT — сумма всех оценок факторов типа T

#### Анализ по категориям
- Группировка факторов по категориям
- Подсчет суммы оценок в каждой категории
- Определение топ-категорий

### Генерация стратегий

#### Алгоритм генерации
1. Выбор топ-N факторов по оценке (N = 5, 7 или 10)
2. Разделение на группы по типам (S, W, O, T)
3. Генерация комбинаций:
   - **SO:** Сильные стороны + Возможности
   - **WO:** Слабые стороны + Возможности
   - **ST:** Сильные стороны + Угрозы
   - **WT:** Слабые стороны + Угрозы
4. Сортировка стратегий по приоритету (сумма оценок факторов)

#### Условия генерации
- Для SO: нужны факторы типа S и O
- Для WO: нужны факторы типа W и O
- Для ST: нужны факторы типа S и T
- Для WT: нужны факторы типа W и T

#### Приоритет стратегий
- Рассчитывается как сумма оценок всех факторов стратегии
- Чем выше приоритет, тем важнее стратегия

### Экспорт отчетов

#### Экспорт в PDF
- Формирование HTML-документа
- Конвертация в PDF через html2canvas
- Поддержка кириллицы
- Многостраничность
- Содержание:
  - Информация о проекте
  - Статистика
  - Распределение факторов
  - Топ-10 факторов (таблица)
  - Сгенерированные стратегии

#### Экспорт в Word
- Формирование структурированного документа
- Использование библиотеки docx
- Поддержка кириллицы
- Содержание:
  - Заголовки и подзаголовки
  - Таблицы (топ-факторы)
  - Текстовые блоки
  - Форматирование

## 📤 Экспорт отчетов

### PDF отчет
- **Формат:** PDF (Portable Document Format)
- **Размер:** Оптимизирован для печати (A4)
- **Содержание:**
  - Титульная страница
  - Информация о проекте
  - Статистика
  - Распределение факторов
  - Топ-10 факторов (таблица)
  - Сгенерированные стратегии
  - Нумерация страниц

- **Формат:** DOCX (Microsoft Word)
- **Структура:**
  - Заголовки и подзаголовки
  - Таблицы с форматированием
  - Текстовые блоки
  - Списки
- **Содержание:** Аналогично PDF отчету

### Использование экспорта
1. Переход на этап "Итог"
2. Нажатие кнопки "📄 Экспорт в PDF" или "📝 Экспорт в Word"
3. Выбор места сохранения
4. Сохранение файла

## 🚀 Быстрый старт

### Первый запуск
1. Запустите приложение
2. На этапе "Проекты" создайте новый проект
3. Введите название и описание
4. Нажмите "Создать проект"

### Добавление факторов
1. На этапе "Ввод факторов" заполните форму
2. Укажите тип, категорию, текст
3. Установите оценки (1-5)
4. Нажмите "Добавить"

1. Добавьте факторы всех типов (S, W, O, T)
2. Перейдите на этап "Стратегии"
3. Выберите количество топ-факторов
4. Нажмите "Сгенерировать стратегии"

### Экспорт отчета
1. Перейдите на этап "Итог"
2. Нажмите кнопку экспорта (PDF или Word)
3. Выберите место сохранения
4. Готово!

- Экспортируйте отчеты для презентаций

- Данные хранятся локально на вашем компьютере
- Совместимость с предыдущими версиями проектов

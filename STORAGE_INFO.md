# Информация о сохранении проектов

## Где сохраняются проекты?

Проекты автоматически сохраняются в домашней директории пользователя:

- **Linux/Mac**: `~/SWOTProjects/` (например, `/home/username/SWOTProjects/`)
- **Windows**: `%USERPROFILE%\SWOTProjects\` (например, `C:\Users\Username\SWOTProjects\`)

## Формат файлов

Каждый проект сохраняется как отдельный файл с расширением `.swot`:
- Имя файла: `{project_id}.swot`
- Пример: `project-1705123456789-abc123def.swot`
- Формат: JSON с заголовком (сигнатура "SWOT", версия формата, версия приложения)

**Примечание**: Приложение также поддерживает старые файлы `.json` для обратной совместимости.

## Автоматическое сохранение

Проекты сохраняются автоматически при:
- Создании нового проекта
- Добавлении фактора
- Изменении фактора
- Удалении фактора
- Генерации стратегий
- Любом изменении данных проекта

## Работа в production

✅ **Всё работает автоматически!**

При сборке приложения через `npm run electron:build:win` (или для Linux):
- Electron API работает так же, как в dev режиме
- Файлы сохраняются в ту же директорию (`~/SWOTProjects/`)
- Пользователь может создавать, редактировать и удалять проекты
- Все данные сохраняются локально на компьютере пользователя

## Проверка сохранения

### В dev режиме:
1. Создайте проект
2. Добавьте факторы
3. Проверьте директорию: `ls ~/SWOTProjects/` (Linux/Mac) или `dir %USERPROFILE%\SWOTProjects\` (Windows)
4. Должны появиться файлы `.swot`

### В production:
1. Установите собранное приложение
2. Создайте проект
3. Проверьте ту же директорию - файлы должны быть там

## Перенос проектов

Пользователи могут:
- Копировать файлы `.swot` из `~/SWOTProjects/` на другой компьютер
- Восстанавливать проекты из резервных копий
- Обмениваться проектами (скопировать `.swot` файл)
- Открывать файлы через меню File → Open или перетаскиванием в окно приложения

## Безопасность

- ✅ Все данные хранятся локально на компьютере пользователя
- ✅ Нет отправки данных в интернет
- ✅ Полный контроль пользователя над своими данными
- ✅ Можно удалить приложение без потери данных (файлы останутся)

## Устранение проблем

### Проекты не сохраняются:
1. Проверьте права доступа к домашней директории
2. Убедитесь, что Electron API доступен (должно быть "✓ Сохранено" в верхней панели)
3. Проверьте консоль на ошибки

### Не могу найти сохранённые проекты:
- Linux/Mac: `ls -la ~/SWOTProjects/`
- Windows: `dir %USERPROFILE%\SWOTProjects\`

### Хочу изменить место сохранения:
Отредактируйте `electron/fileService.js`, функцию `projectsPath()`

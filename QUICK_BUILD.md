# ⚡ Быстрая сборка для Windows

## Простая инструкция (3 шага)

### 1. Установите зависимости
```bash
npm install
```

### 2. Соберите приложение
```bash
npm run electron:build:win
```

### 3. Найдите установщик
Файл будет в папке `dist-electron/`:
- **`SWOT Analyzer Setup x.x.x.exe`**

## Готово! 🎉

Теперь вы можете:
- Скопировать `.exe` файл на любой Windows компьютер
- Запустить установщик
- Установить приложение

## Что делать дальше?

1. **Протестируйте** установщик на Windows
2. **Проверьте**, что приложение работает
3. **Распространите** файл пользователям

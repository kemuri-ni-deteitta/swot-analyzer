# Логика генерации стратегий — технический разбор

## Где происходит генерация

Генерация стратегий — это **этап 4** (индексация 0–5), он называется `StrategiesView`.
Основная логика сосредоточена в двух сервисах:

- `src/services/calculationService.ts` — расчёт score для факторов
- `src/services/strategyService.ts` — непосредственная генерация стратегий

---

## Шаг 1: Расчёт score факторов

**Файл:** `src/services/calculationService.ts`, строки 9–23

Перед генерацией у каждого фактора должен быть рассчитан `score`. Формулы:

```
S / W:  score = significance × impact
O / T:  score = significance × impact × probability
```

- `significance` — значимость, шкала 1–5
- `impact` — влияние, шкала 1–5
- `probability` — вероятность, шкала **0–1** (только для O/T; если не задана — берётся 1)

Максимально возможный score:
- S/W: 5 × 5 = **25**
- O/T: 5 × 5 × 1.0 = **25**

---

## Шаг 2: Выбор топ-N факторов

**Файл:** `src/services/calculationService.ts`, строки 66–71

```typescript
getTopFactors(factors: Factor[], count: number = 10): Factor[]
```

1. Фильтрует только факторы с рассчитанным `score`
2. Сортирует по `score` по убыванию
3. Возвращает первые `count` факторов

Пользователь выбирает `topCount` в интерфейсе: **5** (по умолчанию), **7** или **10**.

> Важно: в топ-N попадают факторы всех типов вместе, без квоты на тип.
> Если, например, все топ-5 — это S-факторы, стратегии с O/T/W не будут сгенерированы.

---

## Шаг 3: Разбивка по типам и условия генерации

**Файл:** `src/services/strategyService.ts`, строки 8–65

Из топ-N факторов формируются четыре массива: `strengths`, `weaknesses`, `opportunities`, `threats`.

Стратегия создаётся только при выполнении условия:

| Стратегия | Условие |
|-----------|---------|
| SO        | `strengths.length > 0 && opportunities.length > 0` |
| WO        | `weaknesses.length > 0 && opportunities.length > 0` |
| ST        | `strengths.length > 0 && threats.length > 0` |
| WT        | `weaknesses.length > 0 && threats.length > 0` |

Итого: максимум **4 стратегии**, по одной на каждый тип.

---

## Шаг 4: Составление стратегии

**Файл:** `src/services/strategyService.ts`, строки 18–65

Константа `maxFactorsPerType = 3` — в каждую стратегию берётся не более 3 факторов каждого типа.

```typescript
factors: [
  ...strengths.slice(0, 3),      // до 3 S-факторов
  ...opportunities.slice(0, 3),  // до 3 O-факторов
]
```

Итого в одной стратегии — максимум **6 факторов** (3 + 3).

### Поля генерируемой стратегии

| Поле          | Значение |
|---------------|----------|
| `id`          | `"so-{timestamp}-{random}"` — уникальный идентификатор |
| `type`        | `'SO'` / `'WO'` / `'ST'` / `'WT'` |
| `title`       | Фиксированный текст (одинаков для всех стратегий одного типа) |
| `description` | Генерируется из текстов факторов |
| `factors`     | Массив факторов, вошедших в стратегию |

## Шаг 5: Генерация описания

**Файл:** `src/services/strategyService.ts`, строки 71–80

```typescript
generateStrategyDescription(factors1, factors2): string
// → "Комбинация факторов: {f1.text, f2.text, ...} и {f3.text, f4.text, ...}"
```

Описание — это простое перечисление текстов факторов. Никакой NLP/AI не используется.

---

## Шаг 6: Приоритет стратегий

**Файл:** `src/services/strategyService.ts`, строки 98–101

```typescript
calculateStrategyPriority(strategy): number
// → sum(factor.score for factor in strategy.factors)
```

Приоритет = **сумма score всех факторов** в стратегии.
В UI стратегии отображаются отсортированными по приоритету по убыванию.

---

## Полная схема работы

```
Ввод факторов (этап 1)
        │
        ▼
calculationService.calculateFactorScores()
  S/W: score = significance × impact
  O/T: score = significance × impact × probability
        │
        ▼
calculationService.getTopFactors(factors, topCount)
  → сортировка по score, срез первых N
        │
        ▼
strategyService.generateStrategies(factors, topCount)
  → разбивка на [S], [W], [O], [T]
  → для каждой пары: если оба массива непустые — создать стратегию
  → в каждую стратегию: до 3 факторов каждого типа
  → description = перечисление текстов
        │
        ▼
useProjectStore.generateStrategies()
  → сохранение стратегий в проект
  → автосохранение в localStorage
        │
        ▼
StrategiesView — вывод стратегий, сортировка по приоритету
```

---

## Ключевые ограничения текущей реализации

1. **Максимум 4 стратегии** — по одной на каждый тип (SO/WO/ST/WT), независимо от количества факторов.
2. **Конкуренция в топ-N** — если топ-5 содержит только S-факторы, ни одна стратегия не будет сгенерирована. Нужно увеличить `topCount` или добавить факторы других типов.
3. **Описание — текстовый шаблон** — никакой интеллектуальной генерации текста нет, только `"Комбинация факторов: X и Y"`.
4. **Фиксированные заголовки** — `title` у всех SO-стратегий всегда одинаков: `"Использовать сильные стороны для возможностей"`.
5. **Нет весовых коэффициентов при отборе** — внутри массива `strengths` порядок факторов тот же, что в топ-N (т.е. сначала идут наиболее значимые S-факторы из общего отсортированного списка).

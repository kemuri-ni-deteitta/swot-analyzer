# Как работают стратегии в SWOT-анализе

## Концепция SWOT-матрицы

SWOT-анализ делит все факторы на 4 квадранта:
- **S (Strengths / Сильные стороны)** - внутренние положительные факторы
- **W (Weaknesses / Слабые стороны)** - внутренние отрицательные факторы
- **O (Opportunities / Возможности)** - внешние положительные факторы
- **T (Threats / Угрозы)** - внешние отрицательные факторы

## Матрица стратегий 2×2

Стратегии формируются путём комбинации факторов из разных квадрантов:

```
┌─────────────────────────────────────────┐
│         ВНУТРЕННИЕ ФАКТОРЫ              │
├──────────────────┬──────────────────────┤
│                  │                      │
│   S (Сильные)    │   W (Слабые)         │
│                  │                      │
├──────────────────┼──────────────────────┤
│   O (Возможности)│                      │
│                  │                      │
│   SO стратегии   │   WO стратегии       │
│   (Агрессивные)  │   (Оборонительные)   │
├──────────────────┼──────────────────────┤
│   T (Угрозы)     │                      │
│                  │                      │
│   ST стратегии   │   WT стратегии       │
│   (Защитные)     │   (Минимизация)      │
└──────────────────┴──────────────────────┘
```

## Типы стратегий

### 1. SO стратегии (Strengths + Opportunities)
**Название:** "Использовать сильные стороны для возможностей"  
**Логика:** Максимально использовать внутренние преимущества для захвата внешних возможностей  
**Пример:** "Используем наш сильный бренд (S) для выхода на новый рынок (O)"

### 2. WO стратегии (Weaknesses + Opportunities)
**Название:** "Преодолеть слабости через возможности"  
**Логика:** Использовать внешние возможности для компенсации внутренних слабостей  
**Пример:** "Используем новую технологию (O) для улучшения слабого процесса (W)"

### 3. ST стратегии (Strengths + Threats)
**Название:** "Использовать сильные стороны против угроз"  
**Логика:** Применить внутренние преимущества для защиты от внешних угроз  
**Пример:** "Используем наш опыт (S) для противодействия конкуренции (T)"

### 4. WT стратегии (Weaknesses + Threats)
**Название:** "Минимизировать слабости и угрозы"  
**Логика:** Защитная стратегия - минимизировать риски от комбинации слабостей и угроз  
**Пример:** "Улучшаем слабую систему безопасности (W) для защиты от кибератак (T)"

## Как работает генерация в приложении

### Шаг 1: Выбор топ-факторов
1. Все факторы сортируются по **score** (оценке)
2. Выбираются топ-N факторов (по умолчанию 5, можно выбрать 3, 5, 7 или 10)
3. Score рассчитывается:
   - Для S/W: `score = significance × impact`
   - Для O/T: `score = significance × impact × probability`

### Шаг 2: Группировка по типам
Из топ-факторов выбираются:
- Сильные стороны (S)
- Слабые стороны (W)
- Возможности (O)
- Угрозы (T)

### Шаг 3: Генерация стратегий
Для каждой возможной комбинации создаётся стратегия:

**SO стратегия:**
- Берутся до 3 лучших сильных сторон
- Берутся до 3 лучших возможностей
- Объединяются в одну стратегию

**WO стратегия:**
- Берутся до 3 лучших слабых сторон
- Берутся до 3 лучших возможностей
- Объединяются в одну стратегию

**ST стратегия:**
- Берутся до 3 лучших сильных сторон
- Берутся до 3 лучших угроз
- Объединяются в одну стратегию

**WT стратегия:**
- Берутся до 3 лучших слабых сторон
- Берутся до 3 лучших угроз
- Объединяются в одну стратегию

### Шаг 4: Условия генерации
Стратегия создаётся только если:
- Есть хотя бы один фактор первого типа (S/W)
- Есть хотя бы один фактор второго типа (O/T)

## Пример работы

**Исходные данные:**
- Топ-5 факторов:
  - S1: "Сильный бренд" (score: 20)
  - S2: "Опытная команда" (score: 18)
  - W1: "Устаревшие технологии" (score: 15)
  - O1: "Новый рынок" (score: 25)
  - T1: "Конкуренция" (score: 22)

**Результат:**
- ✅ SO стратегия: S1 + S2 + O1 → "Использовать сильный бренд и опытную команду для выхода на новый рынок"
- ✅ WO стратегия: W1 + O1 → "Использовать новый рынок для обновления устаревших технологий"
- ✅ ST стратегия: S1 + S2 + T1 → "Использовать сильный бренд и опытную команду против конкуренции"
- ✅ WT стратегия: W1 + T1 → "Минимизировать риски от устаревших технологий и конкуренции"

## Рекомендации по использованию

1. **Выбор топ-факторов:**
   - 3-5 факторов: для быстрого анализа, фокус на главном
   - 7-10 факторов: для детального анализа, больше стратегий

2. **Приоритизация стратегий:**
   - SO стратегии обычно самые приоритетные (агрессивный рост)
   - WT стратегии требуют немедленного внимания (критические риски)

3. **Проверка валидности:**
   - Убедитесь, что все факторы валидны (нет ошибок на этапе 2)
   - Проверьте, что score факторов рассчитан корректно

## Ограничения текущей реализации

1. **Простое описание:** Текущая реализация создаёт простое описание из списка факторов
2. **Одна стратегия на тип:** Генерируется максимум одна стратегия каждого типа
3. **Фиксированное количество факторов:** Берётся до 3 факторов каждого типа

## Возможные улучшения

1. **Множественные стратегии:** Генерировать несколько стратегий каждого типа (разные комбинации)
2. **Умные описания:** Использовать шаблоны для более понятных описаний
3. **Приоритизация:** Ранжировать стратегии по приоритету
4. **Детализация:** Добавить конкретные действия для каждой стратегии
